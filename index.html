CUDA Optimization of Multi-Head Attention

Dominik Djajadi · Individual project

Status: Proposal preparation

Overview

This project investigates the performance of a complete multi-head attention (MHA) forward pass implemented in CUDA C++. It focuses on how communication, memory traffic, and the distribution of work across and within attention heads influence GPU performance.

Starting with a straightforward FP32 implementation, the project will use profiling to guide optimizations and measure improvements in end-to-end layer performance.

Planned approach

  • Implement and validate the complete forward pass with custom CUDA kernels.
  • Profile memory behavior, reductions, and work distribution to identify bottlenecks.
  • Investigate optimizations such as improved locality, warp-level reductions, tiling, and selected kernel fusion.
  • Compare baseline, intermediate, and optimized implementations against a PyTorch reference.

More extensive fusion, online softmax, causal masking, and mixed precision are possible stretch goals.
